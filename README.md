# 🌱 ExplainCrop AI

AI-based plant disease detection system using Intel oneAPI.

- Prediction with confidence score
- Risk level (Low / High)
- Action recommendation
- Visual explanation (heatmap)

## 🧠 Tech Stack
- Python
- TensorFlow / Scikit-learn
- Intel oneAPI (sklearnex)
